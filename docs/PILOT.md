# 双工作区试用清单

目标：验证两项工作能独立推进，同时你可以快速观察和接管。先用合成文字，不使用客户资料。

1. 记录 Windows 版本、Hyper-V、Python 版本，以及首次准备/安装各花多久。
2. 从桌面入口启动。Alt+2显示A，Alt+3显示B，Alt+1返回宿主。
3. A点“人接管”，在测试文本框输入“人工A”；切B确认没有这段文字。
4. A交给AI，在同一框追加“AI验证A”；截图确认。B同步人工输入“人工B”。
5. 对A点“暂停”，确认AI停止，随后显式恢复。不要把接口成功当作文字出现。
6. 运行30分钟，记录失败、重连、误输入和宿主被抢焦点次数。
7. 关闭工作台后从入口重开，确认同一配置仍生效。频道内程序不会因隐藏工作台而停止。

反馈请只附脱敏内容：程序版本、失败步骤、期望/实际结果、耗时和截图。不要发送token、账号、私有配置、二维码或VM磁盘。

验收价值：如果你仍需频繁打开虚拟机管理器、手工修配置或盯着宿主桌面等待，请把它作为产品问题反馈，不算试用成功。
