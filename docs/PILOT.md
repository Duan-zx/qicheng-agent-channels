# 双工作区试用清单

目标：验证两项工作能独立推进，同时你可以快速观察和接管。先用合成文字，不使用客户资料。

1. 记录 Windows 版本、Docker Linux engine、Python 版本（若接 AI），以及首次准备/安装各花多久；只有试双原生 Windows 时才记录 Hyper-V 与客体准备。
2. 从桌面入口启动。Alt+2 显示 Lite 频道一；首次选择双频道时再试 Alt+3；Alt+1 返回宿主。双原生 Windows 另按包内说明试 Alt+4/5。
3. 频道一点“我来接管”，在测试文本框输入“人工A”；若启用频道二，切过去确认没有这段文字。
4. 频道一交给 AI，在同一框追加“AI验证A”；截图确认。若启用频道二，可同步人工输入“人工B”。
5. 对频道一点“暂停”，确认 AI 停止，随后显式恢复。不要把接口成功当作文字出现。两个 AI 任务写同一频道时，只有均接入可选 Task Lease 并实测，才能记为租约隔离通过。
6. 运行30分钟，记录失败、重连、误输入和宿主被抢焦点次数。
7. 从托盘正常退出并重开，再在可安排的时段重启宿主，分别记录页面、下载和自动恢复；未保存的网页表单不保证恢复。

反馈可到 [GitHub Issues](https://github.com/Duan-zx/qicheng-agent-channels/issues/new) 提交脱敏内容：程序版本、失败步骤、期望/实际结果、耗时和截图。不要发送 token、账号、私有配置、二维码或 VM 磁盘。若尚未取得匹配本试用版本的安装包，保持“未测”，不要拿旧 Release 代测。

验收价值：如果你仍需频繁打开虚拟机管理器、手工修配置或盯着宿主桌面等待，请把它作为产品问题反馈，不算试用成功。
