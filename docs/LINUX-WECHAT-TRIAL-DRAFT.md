# Linux 微信双频道试用版（未发布草案）

本草案供发布前审查。Windows 宿主运行两个相互隔离的 Linux 频道；`Alt+1/2/3` 返回本机或查看频道，人工可接管、暂停，Codex 经频道 MCP 读状态与截图，并在人工交给 AI 后输入。原生 Windows 客体是另行安装的可选兼容模式，不在此包中。

## 已验证范围

- 01 机器安装 `0.2.0-alpha.18-local` 后，两频道微信开发者工具 GUI 可启动；安装诊断 21/21、热键切换、人工接管与暂停实测通过。两个频道使用独立资料卷、回环端口与私有凭据。
- 已修正社区工具 CLI 对内部错误仍退出 0 的情况；无效 AppID 会被明确判失败。GUI 退出时频道健康检查返回 503。
- **尚未**在另一台机器完成首次安装；微信登录、合法项目打开、真实编译、双正式 AI 输入任务和宿主重启恢复也尚未通过。登录页出现不等于业务可用。

## 依赖与分发边界

Windows 宿主需本地 Docker Linux engine、.NET Framework 4.x；使用 MCP 桥还需 Python 3.10+ 和支持该桥的客户端。首次构建要从正常上游获取 Python/Debian 依赖和约 195 MB 的固定版本微信开发者工具 DEB，并校验 SHA-256。Docker Desktop 是外部依赖，其免费使用资格由使用者依当前许可判断。启程源码按 Apache-2.0 分发；社区移植源码为 MIT，微信工具内含腾讯组件，不随启程源码或安装 ZIP 分发。Windows 系统镜像和许可也不随包分发。

发布前仍须取得另一台机器的真实安装回执，审清仓库历史中的实机截图与主题素材权利，固定最终 ZIP/源码清单及反馈入口，并取得公开发布授权。此文件不构成正式下载或功能承诺。
